# Third-Party Notices

This package is part of Nishi DSH Suite and targets DeepSeek Harness `0.1.2-alpha.1`.

It resolves, spawns, decodes, and disposes of external vendor CLI processes on the caller's behalf, and normalizes usage information obtained through vendor-owned local integrations. It does not bundle, redistribute, or vendor any third-party CLI, SDK, model runtime, or credential store, and no vendor OAuth/session/token database is copied or redistributed.

DeepSeek Harness client and runtime packages remain peer dependencies so the plugin shares the host's Cordis instance and services rather than installing duplicates.

See the repository root `THIRD_PARTY_NOTICES.md` for repository-wide notices.
