# Project Memory

## Current state
Nishi DSH Suite `0.1.0-rc.3` is the git `main` line, a seven-package family targeting only DSH `0.1.2-rc.1`. All seven packages are `private`; do not install `nishi-dsh-*` from npm (local tarballs via `pnpm pack:local` + `scripts/install-local-profile.mjs`). Previously published `0.1.0-rc.1` has no remaining versions on the npm registry (current family names and retired rc.1 names). The only registry install is DeepSeek Harness. Foundation and Codex are thawed pending independent re-validation; Antigravity is frozen on its documented checkpoint; Claude remains usage-only; Grok is implemented but still needs product-profile acceptance. Windows is NOT TESTED.
